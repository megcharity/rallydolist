WHAT IT ISRALLY

Module one

Sell the experience, not the tech.

RallyTrack is Rally’s own camera-based system for interactive pickleball.

It powers automatic scoring, line and fault calls, stats, leaderboards and arcade-style games. Guests don’t need to know how it works — they need to know why it’s fun.

The easy explanation: think Topgolf, but for pickleball.
Classic

Pickleball, upgraded

Traditional doubles and singles with automatic scoring and real-time line calls.

Arcade

Built for fun

Social game modes, each with its own objective.

First-time RallyTrack players must be onboarded. If guests already know RallyTrack and are comfortable using it, let them get started.

COURT ONBOARDINGRALLY

Module four

New players? Every court, every time.

For guests new to RallyTrack, onboarding is mandatory. The goal: they understand it and actually use it.
  1. Welcome the players.Introduce yourself and let them know you’ll get RallyTrack started.
  2. Add every player.Enter each player on the tablet.
  3. Add the avatars.Help each player get their avatar set up.
  4. Explain the games.Keep it simple, but know each game well enough to recommend one.
  5. Suggest a game.Don’t just hand over the tablet. Recommend one and help them select it.
  6. Get them started.Make sure the group is comfortable and playing before you move on.
Players added. Avatars added. Game suggested. Guests playing.

If guests tell you they’ve played with RallyTrack before and are comfortable with it, you don’t need to repeat the full onboarding.

TABLET BASICSRALLY

Module five

Know the guest-facing controls.

Four areas of the tablet cover almost everything guests will ask about.
PLAYERS

Add each player’s name. Edit or remove players so the lineup is right.

GAMES

Select a mode and switch between Classic and Arcade.

SCORE

Replay a point, award a point to the right team, or edit the score.

HELP

Show guests the Help button so they know how to request assistance.

During onboarding, point out the Help button before you step away. Guests who know where it is are more likely to ask instead of giving up.
BUGS & PLAYER SUPPORTRALLY

Module six

A bug, or a guest who needs help?

When players understand RallyTrack, they’re far more likely to keep playing with it. Don’t let confusion turn into guests giving up on the experience.
Tech bug

RallyTrack gets something wrong.

It calls a point incorrectly, or part of the system isn’t working as expected.

Let a Manager know ASAP.

Player needs help

The tech works. The players are confused.

Don’t just explain from the sideline.

Get on the court and help them.

END OF SESSIONRALLY

Module seven

The tech ends before the reservation.

RallyTrack shuts off a few minutes early. Court time doesn’t. Never rush guests off the court.
15 min before end

10-minute warning

The tablet says RallyTrack turns off in 10 minutes. Guests can acknowledge or extend.

5 min before end

RallyTrack turns off

Guests can review stats and leaderboards.

Reservation ends

Court time is up

Guests keep the court until their PBP reservation ends.
