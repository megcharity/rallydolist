The simple rule

If the guest never received it, void it. If the guest received it, discount it.

Void vs. discount

Every time something comes off a check or is reduced in price, you have to pick the right tool. Using the wrong one makes our reporting inaccurate and hides real problems.

Void
  • The guest never received the item
  • Removed with no record of a sale
  • e.g. wrong item entered, 86'd item, duplicate ring
  • Every void needs a manager PIN
Discount / comp
  • The guest received the item
  • The sale is recorded and tracked in comp reporting
  • e.g. food quality issue, did not like, waste, employee meal
  • Some need manager approval. Always use the most specific discount

The rules

  • Always use the most specific discount available
  • Open discounts only when no existing category fits
  • Don't stack discounts unless leadership specifically approves it
  • Employee discounts don't apply to alcohol unless leadership explicitly approves it
  • Waste discounts are never used for guest-facing recovery
  • Card redemptions need the physical card present and collected
  • All 100% comps and open-value discounts need manager authorization before they're applied
Document it. Every comp and every open % or open $ use goes in the comps section of your shift report: who, why, and who approved it (Chapter 6).

Ringing in a BEO

How every event gets set up in Toast so the check matches the BEO.

  1. Set up the orderSign into Toast POS using the Event BEO number (create one if none was assigned). Select New Order, name the tab with the event number and client or event name (e.g. 2307 Amwins Team Outing), and select Event BEO.
  2. Enter the packageCatering Packages if the BEO shows a package only; Elevations if it shows separate line items. Add the food item and quantity (e.g. Taco Truck), the beverage package and quantity (e.g. Courtside Non-Alc), any upgrades (e.g. protein), and the admin fee.
  3. Split the checkSplit the check and rename the new one. Drag the admin fee into the split check. Add the service charge to the main check and select 20%.
  4. Verify totalsAdd up both checks and confirm the total matches the BEO amount. If it doesn't, note the difference; it will need to be settled in person.
  5. Settle paymentAdmin fee check: select Charge to TS. Main check: take the total paid on the BEO, subtract the admin fee, enter that amount as a deposit, and select Charge to TS. The leftover balance is what the client still owes.
  6. Paid in full?On the admin fee check, select Apply to TS Admin. On the main check, swipe or apply the payment and select Apply to TS.
Before you finalize: double-check the service fee selection, confirm every check total against the BEO, and flag any discrepancy so it's resolved before the event date.

Everyday check tools

From Toast's Help Center. Your screens may look slightly different depending on how Rally's Toast is set up, so practice each one with your trainer.

Move items to another check

  • Select the item on the original check
  • Overflow menu → Split
  • Look Up Check → enter the other check number
  • Select the item → Add → Done

Combine (merge) checks

Open checks only.

  • Payment Terminal → All Checks
  • Three-dot menu → Combine Checks
  • Select checks: the first one you pick is the one the others merge into
  • Select Combine Checks to confirm

Move a check to another table

  • Table service: select the current table, then the new table → Move Check
  • Quick order: open the check → overflow menu → Transfer to Table → pick the table → Move Check

Change the server on a check

Both servers must be clocked in.

  • Open the check
  • Overflow menu → select the server's name (“Change”)
  • Pick the new server → Send or Hold
  • Already closed? Reopen the original server's shift first, transfer, then redo their shift review

Move a payment

Captured card payments can't be moved.

  • Payment Terminal → find the check → Pay ($)
  • Select the payment → Adjust
  • Move Payment to a Different Check → enter the check number → confirm

Reopen a closed check

  • Toast Web: Orders report → open the order details → re-open check
  • On the POS it appears under Payment Terminal → Paid Checks
  • Adding items or acting on it reopens the check
Shift reviews
  • Team members: My Account → Shift Review. Close or transfer open checks, declare cash tips, reconcile cash and tips, close the drawer if needed, clock out, and print the shift review for you
  • You: Manager Activities → Review Employee Shifts. Complete the review for anyone who left without finishing
  • Reopen a shift (this week): Edit → Yes, Make Edits → Re-Open Shift. This clears the tip-out and cash collected, so they'll need to turn in cash and collect tips again
Can't find Combine Checks? Toast calls it a limited-release feature, so ask your GM whether it's turned on at Rally.
